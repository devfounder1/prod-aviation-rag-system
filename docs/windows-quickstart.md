# BUTUZIK AI для Windows x64

Сначала определите, какой комплект вы получили.

**Есть ASSEMBLY_REQUIRED.txt, App и Tools, но нет Runtime и BUTUZIK.AI.exe:**
это исходный комплект для администратора. Он ещё не является установленной
Windows-программой. Сборка описана в полном руководстве, раздел «Администратору».
Не переименовывайте ZIP в EXE. Модели и Windows-библиотеки надо подготовить отдельно.

**Есть BUTUZIK.AI.exe, Runtime, Flet, Ollama, Models и Images:** это собранная
папка. Её сначала должен принять администратор на реальном Windows x64 без сети.

1. Распакуйте ВСЮ папку в доступное для записи место, например
   C:\Users\User\BUTUZIK-AI. Не запускайте из ZIP, Program Files, сетевого диска
   или папки OneDrive. Не переносите один EXE отдельно от папок.
2. Для тестов кода и оформления DOCX нужен запущенный Docker Desktop с Linux
   containers. Администратор заранее устанавливает WSL 2, загружает два локальных
   образа из Images и проверяет linux/amd64. Приложение не делает это само.
3. Закройте другой Ollama в трее, если он занимает порт 11434. Откройте
   Tools\Start-Ollama.cmd. Оставьте появившееся окно открытым.
4. При первом запуске администратор выполняет Tools\Check-Offline.ps1.
   Если проверка падает, устраните причину по полному руководству.
5. Дважды щёлкните BUTUZIK.AI.exe. Сначала загрузятся локальные библиотеки.
6. Для беседы введите «Привет». Для документов сначала добавьте их в базу или
   прикрепите к текущему чату. Для действий включите «Режим агента».
7. Создание/изменение файла подтверждается кнопкой «Разрешить запись».
   Результаты находятся в «Файлах чата», а не рядом с исходным файлом.
8. Закрывайте приложение обычным крестиком. Сохраняйте резервную копию App\data,
   App\agent_workspace и App\config.json перед обновлением.

Подробности: BUTUZIK_AI_User_Guide_RU.docx и App\docs\user-guide-ru.md.
Текущий этап ГОСТ — частичный профиль. Проверяйте страницы и замечания перед
«Сохранить DOCX»; приложение не выдаёт сертификат соответствия.
