# Последовательность переноса ГОСТов для ТУ

Это план применимости и этапов, а не полный разбор правил всех ГОСТов и не исполнительный рецепт.

Форма нашего текущего ТУ: макет для печати с рамками и штампами. Для других запросов вид документа и форма выбираются заново.

Полное применение всех загруженных стандартов одновременно не заявляется. У каждого стандарта своя область; источники не объединяются в одну инструкцию модели.

## 1. ГОСТ 2.114-2016

Для ТУ: ТУ: состав, техническое содержание и согласование. Область: PDF стр. (4,). Этап: Предметный перечень для ручного заключения. Есть отдельный разбор 148 контрольных позиций; решения и технические нормы автоматически не создаются. Дальше: Получить ОТУ/ТЗ и подтвердить открытые условия и ручные заключения.

SHA-256 источника: `556c15185dd0c00e2310d9b96113b252c27788d1e29215005b49e533a18f45a5`.

## 2. ГОСТ Р 2.105-2019

Для ТУ: Основные правила оформления текста ТУ, таблиц, рисунков, содержания и примечаний. Область: PDF стр. (1, 6, 9, 10, 28, 29). Этап: Выбранные правила исполняемого профиля. Выполняются только выбранные правила профиля, включая содержание, заголовки приложений и примечания. Полный стандарт не объявлен автоматизированным. Дальше: Далее разобрать оставшиеся условия, формулы, сноски, ссылки, титульный лист и исключения.

SHA-256 источника: `c3bb3ae4a47c190004bc48225dc8bce53e9579e8b05379a1429d749e28d250ad`.

## 3. ГОСТ Р 2.104-2023

Для ТУ: Основные надписи и дополнительные графы, с учётом бумажной/электронной формы. Область: PDF стр. (1,). Этап: Выбранные правила исполняемого профиля. Существующие рамки и реквизиты сохраняются; есть ограниченные исправления отображения. Нормативная геометрия всех форм не подтверждена. Дальше: Следующий этап: проверка распознанных форм/штампов по размерам и реквизитам без выдумывания подписей.

SHA-256 источника: `2fdb4e0c5dac26f5824dbdb8aafd0f20cacc1a0490222e3ee6d016c0b9df2094`.

## 4. ГОСТ Р 2.106-2019

Для ТУ: Правила текстовых КД, в том числе самостоятельных спецификаций и ведомостей; вид документа определяет применимый раздел. Область: PDF стр. (1, 2). Этап: Разобрана область; перенос правил ещё не завершён. Правила спецификации/ведомостей не накладываются на текст ТУ автоматически. Дальше: Разобрать общие требования и правила для действительно присутствующих видов текстовой КД.

SHA-256 источника: `e83a47f3734de9c8c87334b65ba41446b0589c987a5ee2ac49aa046feb15c57e`.

## 5. ГОСТ Р 2.102-2023

SHA-256 источника: `be33d8f433bbf8e72ae374bd5b7cb5f19c2843e6032a4b148f36330f266098be`.

Сейчас размещается существующее изображение, содержание схемы проверяет человек. Дальше: Подтвердить тип схемы и проверить соответствующий раздел стандарта.
