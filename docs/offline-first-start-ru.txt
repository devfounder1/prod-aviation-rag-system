СНАЧАЛА ПРОЧИТАЙТЕ
BUTUZIK.AI для Windows x64

Если вы получили полный архив с именем OFFLINE, Python, интерфейс, Ollama,
модели, библиотека ГОСТ и два образа уже включены. Скачивать их повторно
и запускать Build-Windows.ps1 не требуется.

1. Перенесите ZIP на Windows x64 и распакуйте ВСЮ папку на локальный диск
   с правом записи. Не вынимайте один EXE. Не запускайте из ZIP или с флешки.
   Потребуется достаточно места и на диске, и для хранилища Docker.

2. Если системные компоненты не подготовлены, попросите администратора
   использовать Installers: WSL x64, Docker Desktop и Microsoft Visual C++.
   Нужно проверить совместимость Windows, виртуализацию и условия установки.
   Возможно, потребуется перезагрузка. Наличие установщика не означает,
   что он уже установлен. Подробности — раздел 7 инструкции Word.

3. Запустите Docker Desktop, дождитесь Linux containers. Один раз импортируйте
   оба tar из Images по разделу 18 инструкции. На следующем обычном запуске
   повторный импорт не нужен. Делайте импорт в профиле Windows будущего
   пользователя: образы WSL из другой учётной записи могут быть недоступны.

4. Запустите Tools\Start-Ollama.cmd. Оставьте это окно открытым.
   Если порт 11434 занят другой Ollama, администратор должен разобраться,
   какая служба запущена. Не завершайте чужие процессы наугад.

5. Выполните Tools\Check-Offline.ps1, как показано в разделе 18 инструкции.
   Для корректного комплекта и подготовленной системы ожидается сообщение
   Readiness checks passed. Если есть ошибка — устраните её до работы.

6. Дважды щёлкните BUTUZIK.AI.exe и проверьте функции по разделу 24.
   Окончательную проверку делают на этой Windows без интернета.
   Полная GUI приёмка на пользовательской Windows ещё не подтверждена.

7. В дальнейшем: Docker Desktop для ГОСТ и тестов, Start-Ollama.cmd,
   затем BUTUZIK.AI.exe. Подробности ежедневной работы — раздел 19.

Результаты находятся в «Файлах чата». Перед обновлением сохраняйте рабочие
данные при закрытом приложении. Не передавайте чаты и документы посторонним.
Файл Word: Инструкция для запуска BUTUZIK AI.docx.

Этот комплект содержит предоставленные PDF ГОСТ. Он предназначен для
согласованной передачи; не загружайте его в публичный репозиторий.
Условия использования Docker и сторонних компонентов проверяются отдельно.
